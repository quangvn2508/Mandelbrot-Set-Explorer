# Mandelbrot-Set-Explorer

The objective of this project is to provide user a responsive application that allows them to view successive magnifications of the Mandelbrot Set. Since this project is the compulsory mini project 2 for module CS2101 (Foundation of Computing) at the University of St Andrews, therefore, I am not allowed to publish any source code for this project. However, I had provided my report which explain my approach and explain the features of the program in details.
